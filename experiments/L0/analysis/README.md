## 공통 원인: σ가 positive 간격보다 크다 (D5)

- σ = 0.5 × 쌍거리 median = 0.554. y_k 사이 최소 간격은 0.15, 이웃 간격은 대체로 0.2–0.4다.
- Gaussian kernel의 필드는 σ보다 작은 구조를 거의 보지 못한다. q̂ = p̂(평활 밀도 일치)는 빨리 이루어지지만,
  그 안에서 점들이 어느 y_j에 붙는지는 지수적으로 약한 힘으로만 정해진다(ill-posed deconvolution).
  float32 잡음 수준(1e-6)에서 ‖V‖ ≈ 0이 되어 멈춘 배치가 "최근접 배정" 기준으로는 w̃와 어긋난다.
- 증거:
  - h_q = 0인 모든 run에서 평활 기준 TV(p̂, q̂) = 0.0001, 최근접 배정 TV = 0.147.
  - F0.2: 배정 행렬의 띠 구조는 w̃와 같고, 오차는 특정 positive 열이 통째로 과다/과소인 세로 줄무늬다.
    가까운 y끼리 질량을 나눠 갖는 비율만 틀렸다는 뜻이다.
  - E0.6 hq0 짝: 최근접 배정 TV 차이 +0.020이지만 평활 밀도 차이 0.0001. 고정점은 같고 σ 이하의 배치만 경로에 따라 다르다.
  - E0.2: memorization은 σ보다 작은 규모의 분리를 요구한다. self 비율이 2k → 38k → 50k 스텝에서 0.21 → 0.281 → 0.288로
    로그적으로만 오른다. h_p를 줄이면(×0.5) 더 빨리 오르다가 0.50에서 정체한다.
- 대조: baseline(release)은 Laplace kernel의 τ가 정규화 거리 0.02–0.2로 날카로워 개별 점을 분해한다.
  그래서 모든 single-bank 실험에서 빠르게 memorization(self 0.95, 자기 y까지 평균 거리 0.044)에 이른다.

해석: L0의 FAIL/INCONCLUSIVE(E0.2, E0.3, E0.6)는 Prop A/C의 "고정점"이 틀렸다는 증거라기보다는,
**사전 등록한 지표(점 단위 배정)가 필드의 해상도(σ)보다 미세한 것을 쟀다**는 데서 온다. 평활 밀도 기준의 결과는
Prop C(q̂ = p̂)와 단서 1(같은 고정점)을 지지한다. 다만 이것은 사후 분석이라 판정을 대신하지 않는다.

## E0.5: Prop E의 대수는 맞고, 유한 표본 동역학이 불안정하다

- 사전 등록한 해석 표(E0.5b prereg): E0.5 FAIL + E0.5b PASS →
  "닫힌 형태는 맞고, 실패 원인은 유한 표본 KDE 꼬리의 동역학 불안정이다".
- 메커니즘(E0.5 smoke 추적): 평형 평균 (1 + λ)/(1 − λ)가 멀어지면 KDE의 꼬리는 가장 바깥 표본에 지배되고, 기울기가
  Gaussian 가정의 σ²/v가 아니라 1이 된다. 서로 멀어지는 두 조건의 상대 repulsion 기울기 2λ가 attraction 기울기 1을 넘는
  λ > 0.5부터 지수적으로 발산한다. 관측: λ = 0.25 수렴, 0.5 이상 발산.
- baseline은 E0.5(M = 2048)에서 50스텝 안에 발산했다(D14: release affinity 바닥 1e-6 때문에 raw 필드 크기가 M에 비례).

## L1 전에 정할 것 (엔지니어 제안)

1. **σ 규칙.** L1 B0의 σ를 데이터 간격과의 비율로 정할지(예: 최근접 이웃 거리 기준). L0 결과는 σ가 이웃 간격보다 크면
   점 단위 mixture가 아니라 평활 밀도만 맞는다는 것을 보여 준다. 생성기 학습에서는 평활 밀도 일치가 목표이므로
   지표도 그 해상도에 맞출지 함께 정해야 한다.
2. **E0.3/E0.2 재검(선택).** σ를 이웃 간격보다 작게 둔 E0.3b(점 단위 Prop C)를 따로 사전 등록할지.
3. **E1.4의 δ = 0 열.** h_p ∝ δ라서 δ = 0에서 AffD = single이 된다(구조적으로 격차 0). h_p를 δ와 분리한 arm을 둘지.
4. **counterfactual λ.** L2(E2.6)의 λ는 0.5 미만에서 고를 것. E0.5는 유한 표본에서 λ ≥ 0.5가 불안정함을 보였다.
5. **정지 기준.** float32에서 ‖V‖ < 1e-6은 잡음 수준이다. L1의 허용 오차는 이보다 크게 잡을 것.
6. **이웃 복사 지표.** 용량이 충분하면 AffD 평형은 이웃 positive의 혼합(학습 샘플 복사)이다. 자기/이웃 positive와의
   거리를 나눠 재는 지표를 L1에 넣을지.
7. **MMD-joint arm.** 정규화만 다른 결합 kernel MMD를 E1.3 통제군 옆에 둘지(L4까지 기다리지 않고).
