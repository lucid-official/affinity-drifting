## 원인

1. **G4 운영 정의 오류.** "조건 없는 drifting"을 K5 + h_q = 0으로 정의해, 각 조건이 자기 생성 샘플 8개끼리만 밀어냈다.
   batch가 하나의 분포가 아니라 8개짜리 64조각으로 따로 맞춰진다. release의 조건 없는 drifting은 batch 전체끼리 밀어낸다
   (여기서는 h_p = h_q = ∞). 8개로 추정한 repulsion(가중 평균 비율 추정량)은 편향이 커서 분포가 좁아진다.
2. **repulsion 표본 수.** 같은 h_q = 0에서도 조건당 64개면 0.578 → 0.247. B0의 M = 8은 모든 arm의 절대 품질을 제한한다.
3. **국소 kernel만으로는 전역 수송이 약하다.** 전체 batch에서도 σ = 0.071 하나로는 0.22에서 정체(3배 학습해도 0.222).
   다중 스케일(kNN 폭 → median heuristic)을 더하면 0.175.
